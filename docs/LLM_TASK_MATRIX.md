# LLM task matrix — localvideotranscriber

Scan-first map: **intent → where to edit → anchor symbols → how to validate → traps**. Paths relative to repo root. See also `docs/LLM_GUIDE.md`, `docs/IPC_PROTOCOL.md`, `docs/CHANGE_PLAYBOOK.md`.

| Intent | Primary files | Key symbols | Validation / tests | Notes / pitfalls |
|--------|---------------|-------------|--------------------|------------------|
| Add or change a Python stdin `method` and wire Electron | `backend/main.py`; `electron/main.js` | `main()` dispatch; `send()`; `sendToPython()`; `rpcCall()` | `docs/IPC_PROTOCOL.md`; smoke `npm start` | Typed RPC resolves `pendingRpc` by `id` but `sendToRenderer` still forwards every line to `python-message` — duplicates possible. |
| Add IPC from renderer (invoke/send) end-to-end | `electron/main.js`; `electron/preload.js` | `ipcMain.handle` / `ipcMain.on`; `contextBridge.exposeInMainWorld('api', …)` | Manual UI exercise | `preload.js` `onMessage` registers `ipcRenderer.on` with no unsubscribe — multiple callbacks stack. |
| Change start/cancel UX and progress display | `electron/renderer/app.js`; `electron/renderer/index.html` | `window.api.startProcess`; `queueProgressUpdate`; `flushProgressUpdate`; `btnStart` wiring | Manual | `estimateETA()` exists but is not on the main start path (`LLM_GUIDE.md`). |
| Debug Python process lifecycle (spawn, stdin, errors) | `electron/main.js` | `startPython()`; `spawn(..., 'main.py')`; `pythonReady`; `sendToPython` guard | Console stderr `[Python]`; manual | `pythonReady` is set right after `spawn`; first `process` can race slow Python import on weak machines. |
| Orchestrate full single-source job | `backend/pipeline.py` | `Pipeline.run` | `backend/tests/test_pipeline.py` (`TestPipelineRun`); `backend/tests/integration/test_integration_pipeline.py` | Heavy stages separated by `gc.collect()` — keep ordering consistent with memory assumptions. |
| Orchestrate multi-source batch | `backend/pipeline.py` | `Pipeline.run_batch` | `TestPipelineBatch`; `TestBatchPipeline` in `test_integration_pipeline.py` | Batch uses `stage: "batch"` style progress; differs from single `run`. |
| Cooperative cancel | `backend/pipeline.py`; `backend/main.py`; `electron/main.js` | `Pipeline.cancel`; `method: "cancel"`; `ipcMain.on('cancel-process')` | `test_pipeline.py`: `test_pipeline_cancel`, `test_run_cancellation`, `test_run_batch_cancellation`; manual cancel click | Ensure cancel event is checked in long inner loops. |
| Config fields, defaults, validation | `backend/config.py` | `Config` (Pydantic `BaseModel`) | `backend/tests/test_config.py` | Single source of truth for field names sent as `config` dict over stdin. |
| Normalize runtime overrides | `backend/pipeline.py` | `_normalize_runtime_config` | `test_pipeline.py` | Mutates `Config` in place; keep aligned with UI-sent keys. |
| Harden source path / URL and output dir | `backend/pipeline.py` | `_validate_source`; `_validate_output_dir` | `TestSourceValidation` in `test_integration_edge_cases.py` | Output dir depth cap (`base_max_depth`); symlink/path edge cases. |
| Core ASR: model load, decode, language | `backend/transcriber.py` | `transcribe`; `ASRRuntime`; `_resolve_device_and_compute` | `test_integration_transcription.py` (`TestTranscriptionStructure`, `TestLanguageDetection`) | Device/compute resolution affects performance and OOM risk. |
| Long-media ASR strategies | `backend/transcriber.py`; `backend/pipeline.py` | `_transcribe_chunked`; `_transcribe_streaming_source`; `_transcribe_prechunked` | Integration suite + `test_data/` assets | Three paths — regression in one does not imply others. |
| Merge diarization with segments | `backend/transcriber.py` | `_merge_diarization_with_segments` | `TestDiarizationIntegration` in `test_integration_pipeline.py` | Order/timestamp alignment sensitive. |
| Speaker diarization backends | `backend/diarizer.py` | `diarize`; `_diarize_energy_based`; `_diarize_pyannote`; `_diarize_speechbrain` | `backend/tests/test_diarizer.py` | Backend chosen via `config.diarize_backend` (`energy`, `pyannote`, `speechbrain`). |
| Summarization, chunking, map-reduce | `backend/summarizer.py` | `summarize`; `_tree_reduce`; `_chunk_segments`; `_llm_call` | `test_summarizer.py`; `test_integration_summarization.py` | Checkpoints: `_build_summary_checkpoint_path`, `_load_summary_checkpoint`, `_save_summary_checkpoint`. |
| Summary mode prompt text | `backend/prompts/notes/`, `call_check/`, `factcheck/`, `tldr/` (`chunk.txt`, `final.txt`); `summarizer.py` | `_load_prompt_template` | `TestLoadPromptTemplate` in `test_summarizer.py` | Legacy: `backend/prompts/chunk_summary.txt`, `final_summary.txt`. |
| Single-file Markdown report shape | `backend/formatter.py` | `format_markdown`; `_format_timestamp`; `_get_speaker_name` | `TestFormatMarkdown` in `test_formatter.py` | Drives `{stem}_summary.md` content from pipeline. |
| Batch Markdown aggregation | `backend/formatter.py` | `format_batch_markdown` | `TestFormatBatchMarkdown`; batch pipeline tests | Distinct layout vs single `format_markdown`. |
| Download remote media | `backend/downloader.py` | `download_audio` | Manual URL run; integration with network | yt-dlp behavior and errors surface as pipeline failures. |
| FFmpeg duration, extract, chunk/slice helpers | `backend/audio.py` | `get_duration`; `extract_audio`; `extract_audio_chunks`; `extract_audio_slice` | `test_integration_audio.py` (`TestDurationProbe`, `TestAudioExtraction`, `TestAudioChunking`) | FFmpeg must be on PATH (`README.md`). |
| ETA estimation and stats persistence | `backend/eta.py`; `backend/main.py` | `estimate`; `format_eta`; `record_run`; `method: "estimate_eta"` | RPC `estimate-eta` from preload; unit behavior via callers | Stats file path from `_get_perf_stats_path` — mind permissions. |
| Model list / presets for UI | `backend/models_registry.py` | `list_models`; `scan_local_ggufs`; `resolve_llm_preset` | `ipcMain.handle('list-models')` → `list_models` | `list_models(project_root)` must receive correct project root from Python side. |
| GPU / VRAM reporting for settings UI | `backend/summarizer.py`; `backend/main.py` | `_detect_gpu_info`; `method: "get_gpu_info"` | `ipcMain.handle('get-gpu-info')`; manual | Returns dict consumed by renderer badge logic. |
| Expose `process_batch` from desktop UI | `electron/main.js`; `electron/preload.js`; `electron/renderer/app.js` | `method: "process_batch"` already in `main.py` | None wired today — add IPC + UI | `LLM_GUIDE.md`: Python supports batch; Electron only sends `process`. |
| Unit-test pipeline contracts (no heavy models) | `backend/tests/test_pipeline.py` | `TestPipelineInitialization`; `TestPipelineProgressCallback`; `TestPipelineRun`; `TestPipelineBatch` | `pytest backend/tests/test_pipeline.py` | Uses mocks/fixtures — not a substitute for integration. |
| Integration end-to-end pipeline | `backend/tests/integration/test_integration_pipeline.py` | `TestPipelineEndToEnd`; `_run_pipeline` | `pytest backend/tests/integration` + deps | Requires environment per `conftest.py` / `test_data/README.md`. |
| Transcription quality / speed regression | `backend/tests/integration/test_integration_transcription.py` | `TestTranscriptionAccuracy`; `TestRealtimeFactor`; `TestFastPathParity` | Pytest with reference transcripts | Depends on `test_data/` and optional reference `.txt`. |
| Robustness: silence, short clips, bad paths | `backend/tests/integration/test_integration_edge_cases.py` | `TestSilenceHandling`; `TestCorruptedFiles`; `TestPathHandling` | Pytest integration | WAV builders `_make_silence_wav`, `_make_tone_wav` in same file. |
| Summarization throughput / language | `backend/tests/integration/test_integration_summarization.py` | `TestSummarizationThroughput`; `TestSummaryLanguage` | Pytest integration | LLM-heavy — longer runs. |
| Local benchmark / report harness | `backend/tests/integration/run_benchmarks.py`; `backend/tests/integration/conftest.py` | `run_benchmarks`; `MetricsCollector`; `BenchmarkResult` | From repo root: `python backend/tests/integration/run_benchmarks.py` (flags in file docstring) | Optional HTML via `--html` (`webbrowser`). |
